# PRIVACY & DATA PROTECTION AUDIT (GDPR / CCPA)

## 1. Data Collection Assessment
* **Personal Data Ingested**: Visitor birthday wishes (names + message text), photo memories, and love notes.
* **Tracking & Analytics**: No third-party ad trackers, tracking pixels, or intrusive behavioral analytics SDKs are embedded.
* **Data Minimization**: Exam Arena and games store local anonymous progress; user PII is neither requested nor required for game participation.

## 2. Controls & Rights
* Wishes and media can be reviewed, edited, and deleted at any time by the administrator via the Admin Panel.
* No telemetry or user input is sent to unapproved external third parties.

## 3. Verdict
Complies with data minimization and user privacy best practices.
